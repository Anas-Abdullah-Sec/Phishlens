Drop an .eml file anywhere on this page

How do I get an .eml file?
  • Gmail Open the message, press the three dots, choose Download message.
  • Outlook Drag the message onto your desktop, or use File, Save As.
  • Apple Mail Select it, then File, Save As and pick Raw Message Source.
  • Thunderbird Right-click the message and choose Save As.
Look links and files up online (optional)

Checks links, attachment hashes and the sender IP on VirusTotal and AbuseIPDB. Only those details are sent, never the email. Free keys are rate-limited, so this can take a minute.
